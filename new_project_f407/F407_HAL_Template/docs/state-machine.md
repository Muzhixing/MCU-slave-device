# 整合状态机

入口位于User/main.c。主循环依次处理HWT101、串口、SystemControl和MotorControl，使用中断接收及定时输出；不再保留单外设演示入口。

## 状态与调度

|编号|状态|行为|
|---|---|---|
|0|禁用|底盘PWM停止，步进脉冲停止，舵机保持当前软件角度，泵关断|
|1|就绪/航向保持|目标速度0且航向到位；持续检测航向偏移|
|2|轴运动|底盘停止；先lift，后slide；两轴不同时运行|
|3|底盘运动|四轮速度PID+航向外环|
|4|故障|停止输出，禁止自动恢复|
|5|等待停车|切换轴/底盘及方向反转时的500ms等待|

新合法运行帧替换待执行目标。当前有限步进动作先完成，再执行最新绝对位置目标；禁用帧立即停止并保留已输出脉冲计数。轴目标优先于底盘，轴完成后等待500ms再恢复底盘。舵机可独立渐变到目标，步进忙时仍可更新。

上电等待HWT稳定约1秒建立相对参考。角度外环10ms运行，误差取最短角：15×角误差−2×角速度，限幅±600；1°且角速度≤3°/s进入保持，偏离超过2°退出保持。正角左转。

四轮目标：A=VX−VY−转向，B=VX+VY−转向，C=VX+VY+转向，D=VX−VY+转向；平移比例乘12，统一归一化到1200。轮速为历史算法单位而非标准RPM，换算为delta×60000×2/(11×15×采样ms)。速度PID周期10ms，A/C/D增益30/20/0、B增益23/20/0，缩放100；输出最大30%PWM。

## 保护与限制

- 两轴必须分别确认机械零点后才允许任何运行。保护范围0～175mm，预留总行程180mm的5mm余量。
- 软件位置来自已发脉冲，不能检测打滑、丢步、外力位移或断电移动；无自动回零、无碰撞检测。
- HWT数据过期300ms或连续角失效时停机。连续角链中断后可能必须重启并重新建立参考。
- UART错误/溢出、电机反馈缺失、反馈反向或调度超时均有故障路径。电机故障锁定需要排除原因后重启；其他故障先发禁用帧清除，再显式使能。
- 500ms等待用于方向/动作切换，不是通信超时。按用户要求，不启用断连500ms自动停车。
- 超声不参与自动避障。水泵只有关断逻辑。
- 初始化失败/Error_Handler关闭舵机信号、步进脉冲、水泵及电机后停留；软件停脉冲不等于切断步进驱动保持电流。
