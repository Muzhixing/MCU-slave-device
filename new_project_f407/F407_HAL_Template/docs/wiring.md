# 接线与资源

以下以当前源码和保留的PCB资料为准。共同地必须连通；信号线按网络名核对，不能把驱动电源接到MCU引脚。原理图：[schematic.jpg](hardware/schematic.jpg)。

## 四路直流电机

|轮|位置|PWM|方向输出|编码器A/B|编码器修正|
|---|---|---|---|---|---|
|A|左前|PE6 / TIM9_CH2|PB15、PD1|PA0、PA1 / TIM2|-1|
|B|左后|PE11 / TIM1_CH2|PD2、PD3|PA6、PA7 / TIM3|-1|
|C|右前|PE13 / TIM1_CH3|PD4、PD5|PD12、PD13 / TIM4|+1|
|D|右后|PE14 / TIM1_CH4|PD6、PD7|PC6、PC7 / TIM8|+1|

PWM 10.5kHz（PSC15、ARR999）。C/D电气输出方向已反向，以正目标对应车体前进为约定。编码方向修正只做一次，不能对速度取绝对值。当前PID限幅30%PWM，协议100%是速度目标比例，不能理解为100%占空比。

## 串口、传感器与舵机

|外设|F407连接|设置|
|---|---|---|
|HC-08/上位机串口|PC10 USART3_TX→模块RX；PC11 USART3_RX←模块TX；共地|115200、8N1；模块电源按实际模块额定值|
|HWT101|PA3 USART2_RX←HWT101_TX；共地|115200、8N1；PA2未用于本次通信|
|180°舵机|PE5信号、板上5V、GND|TIM5中断生成20ms周期，500～2500µs，默认90°；PC8不是当前舵机输出|
|超声波|PB13→Trig，PB14←Echo，电源和GND|TIM12_CH1捕获；约200ms采样；Echo到MCU必须满足3.3V输入要求，现有分压/电平转换需核对|
|水泵|PE1控制|本版本仅输出低电平关闭；水泵硬件工作未确认|
|下载器|PA13 SWDIO、PA14 SWCLK、GND、参考3.3V，可接NRST|ST-Link SWD；PA15用于步进，不能启用全JTAG占用|

## 步进轴（脉冲，不用CAN）

|轴|接口|DIR|STEP|接口电源脚|
|---|---|---|---|---|
|lift升降|CN1|3脚 PE8|4脚 PE9|6脚3V3、7脚GND、8脚VM|
|slide横杆|CN2|3脚 PD0|4脚 PA15|6脚3V3、7脚GND、8脚VM|

上表为PCB端网络，不代表驱动排线顺序；对应驱动端的Dir、Stp、供电和公共端需逐根核对。COM/EN实际接法尚无完整确认记录，不假设已由MCU控制。电机A+/A-/B+/B-是线圈端，不能接控制信号。

现有X42驱动需配置为脉冲控制、正确使能、与3200脉冲/转换算一致的细分设置。菜单照片仅作现场参考，不保证光标位置代表保存值。没有限位开关，不启用碰撞/无感回零。

lift正方向向下：800脉冲/mm，软件范围0～175mm，最高约4000Hz。slide正方向沿最终约定“向前”：180mm对应515°，约25.4321脉冲/mm，范围0～175mm，最高约400Hz。早期将同一物理方向称为“后移”，后来仅改称“前移”；复测以机械起点和增大坐标一致为准。

TIM7统一125µs脉冲调度，双轴串行运动。TIM5用于舵机、TIM12用于超声；TIM2/3/4/8编码器，TIM1/9电机PWM。超声共享TIM8_BRK_TIM12中断，未启用TIM8刹车功能。

原理图CAN部分不可作为本固件连接依据；当前不初始化CAN。任何CANH/L必须经过收发器，不能直接作为MCU逻辑收发信号。
