# 复测步骤

## 主机与构建

1. `python tests/run.py`：使用生产协议、轴、状态机、脉冲源码，模拟时钟和寄存器。
2. Keil Rebuild：检查0错误/0警告，目标器件及Flash/SRAM范围。
3. 对比firmware内SHA256与要下载的HEX。主机测试不验证电气连接、真实脉冲时序、UART中断和机械动作。

## 上电与零点

将lift放在顶部、slide放在约定原点；支撑升降负载，首次复测让底盘轮子离地。上电舵机到90°，底盘与轴应静止。等待HWT参考有效后，发禁用00，再发确认零点06。状态bit1/2/5应成立。软件零点确认不会自动移动机械机构。

## 分项

1. 零速度使能01：应保持上电方向；轻微转动车体后，底盘应修正。保持误差存在1°/2°迟滞。
2. 保持轴位置，给90°（2D）和270°（87）：确认左正右负、到位保持。每次都发送完整目标。
3. 给VX±20、VY±20：确认四轮方向。反向切换有500ms等待。禁用包应停止。
4. 保持底盘目标速度0，lift/slide从0到30到60mm：先升降后横杆，状态位置应约300、600（0.1mm）。重复同一帧不能再移动30mm。
5. 接近175mm时发送180或255：应只到175，不越界；再发0应返回软件零点。行程与换算先用尺量核对，累计脉冲不是物理测距。
6. 轴运动中禁用：位置保留部分行程；重新发目标应从当前计数继续。不要在非机械零位随意发确认零点。
7. 舵机先测试90°附近，再逐步扩展；状态角度只是软件目标进度。
8. 超声用已知距离目标核对，超时状态FFFF；不期望自动避障。
9. 故障复测：静止状态断开HWT信号应显示无效；运行时数据失效应停车。UART断连本身没有500ms无报文停车，使用显式停止命令。

记录每项：固件SHA256、发送HEX、返回20字节、实际方向/距离、结果。当前用户确认的是清理前整合包成功；清理后仍应按本清单现场复测。水泵不测试。
