# 四轮后续验证

当前基线为 [2026-11-23悬空低速验收版本](four-wheel-filter-20261123.md)。

1. 落地持续遥控前补齐MCU失联自动停车，并测试断线和重连。现固件运动命令持续有效，上位机正常发送禁用成功不等于通信中断时会自动停车。
2. 逐路核对PWM输出、编码器与物理轮位配对。已手转确认编码器D左前、B右前、A右后、C左后；再依据实际安装与轮子滚子方向核对麦克纳姆混合公式，验证横移和原地转向。
3. 验证负载下起步、停车及长时温升；在更高转速下检查滤波后的有效脉冲宽度和计数完整性。悬空8%正反向各120秒的结果不覆盖这些工况。
4. 建立可靠的逐轮目标、编码器增量、速度和PWM遥测，再评估低速量化、PI误差及是否需要调参。原状态包没有这些字段。
5. 单独定位运行态SWD异常读回及可能的编码器电气干扰；保留原始记录，定量分析使用可靠的采集通道。
6. 本次完整映像由Keil切换为GNU构建，已检查重启、串口和四轮；恢复机构作业前补做ABC动作回归。
