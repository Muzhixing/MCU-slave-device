## 成功时的接线

### STM32与TJA模块

| STM32F103C8T6 | TJA模块 | 说明 |
| --- | --- | --- |
| PA12 / CAN1_TX | TXD | STM32向CAN收发器发送逻辑数据 |
| PA11 / CAN1_RX | RXD | STM32接收CAN收发器输出的数据 |
| 5V | VCC | TJA模块供电 |
| GND | GND | STM32与TJA模块共地 |

### TJA模块与电机CAN模块

| TJA模块 | 电机CAN模块 | 说明 |
| --- | --- | --- |
| CANH | CHAN | CAN高线，模块丝印中的 `CHAN` 按CANH使用 |
| CANL | CHAL | CAN低线，模块丝印中的 `CHAL` 按CANL使用 |

电机驱动器使用自己的动力电源。CANH和CANL使用双绞线连接；总线两端按需要保留120欧终端电阻。不能把PA11、PA12直接接到CANH、CANL，中间必须经过TJA收发器。

## 钢丝电机恢复后的驱动器设置

恢复出厂以后先断电重启，再重新执行编码器校准。校准时尽量让电机空载或轻载，避免钢丝被拉紧。

| 菜单项 | 本次设置 | 作用 |
| --- | --- | --- |
| MotType | 1.8° | 对应当前电机和每圈3200脉冲的计算 |
| Cal | 执行一次 | 重新标定编码器和电机参数 |
| P_Pul | PUL_FOC | 闭环FOC控制 |
| P_Serial | CAN1_MAP | 将通信接口设置为CAN |
| En | Hold | 不依赖外部EN引脚，仍可通过协议使能 |
| MStep | 16 | 1.8°电机每圈3200脉冲 |
| MPlyer | Enable | 打开内部细分插补 |
| CAN_Baud | 500000 | 与STM32程序一致 |
| ID_Addr | 1 | 原工程钢丝/升降电机地址 |
| Checksum | 0x6B | 与Emm V5代码一致 |
| Response | Both | 返回接收确认和到位信息 |
| S_Vel_IS | Disable | 速度值不缩小10倍 |
| O_POT_En | Disable | 本次安全测试暂时关闭上电自动回零 |

原工程地址保持为：钢丝升降电机地址1，横杆电机地址2。之前测试中钢丝地址曾设置为3，本次已经重新统一到原工程的地址1。

## CAN配置

STM32时钟为72 MHz，APB1为36 MHz。CAN参数为：

```text
Prescaler = 4
SJW       = 1 TQ
BS1       = 13 TQ
BS2       = 4 TQ
Mode      = Normal
```

CAN位速率计算：

```text
36 MHz / 4 / (1 + 13 + 4) = 500 kbit/s
```

程序使用扩展帧。扩展帧ID由电机地址和分包序号组成：

```text
ExtId = (address << 8) | packet_index
```

钢丝电机地址为1，因此第一帧ID为 `0x100`，第二帧ID为 `0x101`。

## 实验结果

1. 钢丝电机恢复出厂后，仅恢复CAN波特率和地址还不够，必须重新选择电机类型并执行 `Cal` 校准。
2. 配置 `P_Serial=CAN1_MAP`、`CAN_Baud=500000`、`ID_Addr=1`、`Checksum=0x6B` 后，钢丝电机能够接收当前工程的CAN命令。
3. 本次地址1、方向1、30 RPM、加速度5、5 mm移动测试成功。
4. 原工程的丝杠换算 `800脉冲/mm` 与驱动器1.8°、16细分设置匹配。
5. 外接TJA收发器使用PA11/PA12可以正常工作，证明之前的问题不在Emm V5运动数据本身，而在CAN物理层、驱动器通信映射或恢复后的参数没有统一。
6. 当前仍关闭上电自动回零。以后恢复自动回零前，需要单独确认回零方向、机械端点以及无感回零的电流和时间阈值，不能直接使用未经验证的数值。
