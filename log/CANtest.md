# CANtest 分支说明

## 分支用途

`CANtest` 是 STM32F103C8T6 的双步进电机独立测试分支，只验证外接 CAN 收发器、ZDT X42/Emm V5 驱动板、钢丝机构、横杆机构和蓝牙控制。该分支不包含四路地盘 PID，详细实验过程见 `log/20260907.md` 和 `log/20260908.md`。

当前已完成的实物测试包括：CAN 通信、横杆运动、钢丝运动、钢丝无感归零、两台驱动器同时挂载，以及 HC-08 双摇杆控制。

## 通信配置

- CAN1 工作在 Normal 模式，波特率为 500 kbit/s。
- CAN 使用扩展数据帧，扩展 ID 为 `(电机地址 << 8) | 分包序号`。
- Emm V5 命令使用固定校验字节 `0x6B`。
- 钢丝驱动器地址为 1，横杆驱动器地址为 2。
- 两台驱动器的 CANH/CANL 并联，通过地址区分，不能设置为相同地址。
- HC-08 使用 USART2、115200、8N1，接收 `[j,LX,LY,RX,RY]` 或原工程 `B3...B4` 十字节数据包。

## 接线

### STM32 与 HC-08

| STM32 | HC-08 |
| --- | --- |
| PA2 / USART2_TX | RXD |
| PA3 / USART2_RX | TXD |
| GND | GND |

### STM32 与外接 TJA CAN 收发器

| STM32 | TJA 模块 |
| --- | --- |
| PA12 / CAN1_TX | TXD |
| PA11 / CAN1_RX | RXD |
| 5V | VCC |
| GND | GND |

### CAN 总线

```text
TJA CANH ──┬── 钢丝驱动器 CHAN/CANH
           └── 横杆驱动器 CHAN/CANH

TJA CANL ──┬── 钢丝驱动器 CHAL/CANL
           └── 横杆驱动器 CHAL/CANL

GND     ───┬── 钢丝驱动器通信地
           └── 横杆驱动器通信地
```

驱动器动力电源和电机 A+/A-/B+/B- 继续使用已验证的原车线束。CANH、CANL 不能直接接 PA11、PA12，中间必须经过 CAN 收发器。断电测量总线两端时，两个 120Ω 终端并联通常约为 60Ω。

## 驱动器配置

两台驱动器均使用 1.8° 电机、16 细分、`PUL_FOC`、`CAN1_MAP`、500 kbit/s、固定 `0x6B` 校验和 Both 应答。钢丝地址 1，横杆地址 2。

钢丝电机启动后由 STM32 设置并触发无感归零：模式 2、方向 0、速度 30 RPM、超时 20000 ms、堵转检测 30 RPM/800 mA/60 ms。归零等待完成后才开放蓝牙控制。

## 蓝牙测试逻辑

- 左摇杆 Y 控制钢丝升降：正方向 1，反方向 0，速度 30 RPM。
- 右摇杆 Y 控制横杆左右移动：正方向 0，反方向 1，速度 10 RPM。
- 摇杆死区为 ±20，单条相对位置命令映射为 1、2、3 或 5 mm。
- 摇杆保持时按预计运动时间继续下发小段命令，回中后停止新增命令。

这些参数是当前实验配置，不是最终整机配置。最终同时接入四路地盘电机时，PA11/PA12 会与地盘 PWM、编码器资源冲突，需要重新分配 CAN 引脚并重新做整机测试。
