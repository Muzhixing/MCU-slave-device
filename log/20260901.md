# 2026-09-01 蓝牙开环底盘测试记录

## 1. 本次测试方案

本次暂时去除 WT101 航向 PID，不使用姿态传感器进行航向反馈，仅通过蓝牙串口控制四个底盘电机进行开环运动测试。

蓝牙摇杆数据直接映射到底盘的前后移动、左右横移和原地旋转。当前蓝牙测试模式下，摇杆输出保持线性分级变化，每个电机的最终 PWM 被限制在 `699/999`，即最高约 70%。

## 2. 当前测试结果

四电机开环控制基本成功，已经能够通过蓝牙控制小车完成以下基础动作：

- 前进；
- 后退；
- 向左横移；
- 向右横移；
- 原地左转；
- 原地右转；
- 摇杆归中后停车。

因此，当前蓝牙串口接收、摇杆数据解析、麦克纳姆轮运动计算和四电机 PWM 输出链路已基本跑通。

## 3. 当前控制限制

当前测试去除了 WT101 航向 PID，只使用电机开环控制。由于缺少陀螺仪航向反馈，控制器无法检测车体的实际航向变化，也无法自动进行航向纠偏。

因此目前存在以下限制：

- 无法保证小车前进或横移时车头始终保持原来的方向；
- 无法自动补偿四个电机、车轮和地面摩擦之间的差异；
- 转向只能按照开环 PWM 输出执行，不能保证最终转角准确；
- 受到负载、供电和地面条件影响时，实际运动轨迹可能发生偏移。

WT101 航向 PID 的作用是根据目标航向和实际航向之间的误差调整旋转量。当前关闭该反馈后，基础运动可以执行，但不具备航向保持和转向闭环能力。

## 4. 机械结构问题

车身下地运行后发现底盘刚性不足。车架在电机驱动力、车轮接触力和负载作用下容易发生变形，进而导致车体来回晃动。

该现象可能产生以下影响：

- 四个麦克纳姆轮不能稳定、均匀地接触地面；
- 各车轮实际受力和摩擦力不断变化；
- 开环控制下的直线、横移和旋转轨迹进一步恶化；
- 即使后续恢复 WT101 航向 PID，机械晃动仍可能影响控制效果。

## 5. 当前结论

本次去除 WT101 PID 后，蓝牙控制四电机开环运行的基本功能测试成功，但当前整车仍存在两个主要问题：

1. 缺少陀螺仪航向反馈，无法保证车头方向和转向精度；
2. 车身结构刚性不足，落地运行时容易变形并产生往复晃动。

后续若要提高整车运动稳定性，需要分别处理控制反馈和机械结构问题。仅调整 PWM 数值不能同时解决航向漂移和车体变形。
